\section{結果の考察}

\subsection{on-device学習による性能改善の特性}

表\ref{tab:results_before},表\ref{tab:results_after}および表\ref{tab:improvement}より,
on-device学習前後で以下の性能変化が確認された：

\begin{itemize}
    \item Accuracy：77.8\% → 85.2\%（+7.3\%pt）
    \item Stability：78.1\% → 85.2\%（+7.1\%pt）
    \item Confidence：84.9\% → 84.4\%（-0.5\%pt）
\end{itemize}

on-device学習後にAccuracyおよびStabilityが向上した一方で,
Confidenceはほぼ変化しなかった.
識別性能と予測の安定性が改善されつつ,
モデルの確信度が過度に変化していないことを示している.

本研究では,隠れ層を固定し出力層のみを更新する学習方式を採用した.
この構成により,sEMG特徴量が写像される特徴空間は保持されたまま,
クラス間の判断境界のみが装着条件や個人差に応じて調整される.
Confidenceが学習前後でほぼ一定であったことは,
少量データによる学習であっても過学習を抑制し,
安定した適応が行われたことを示唆している.

クラス別に見ると,事前学習時に識別精度が低かったpinchジェスチャにおいて,
大きな性能改善が確認された.
一方で,事前学習時点ですでに高精度であったpaperジェスチャでは,
判断境界の調整に伴うわずかな精度低下が見られた.
全体としては平均性能が向上しており,
識別が不安定であったクラスへの適応が有効に機能した.

以上より,本研究で採用した最終層のみを更新するon-device学習手法は,
確信度を維持したまま識別性能を改善できる点で,
リアルタイム動作を前提としたsEMGインタフェースに適した特性を持つといえる.
\section{課題}

本研究では単一被験者による評価に限られており,
被験者間差に対する一般性については検討できていない.
また,長時間使用時における学習効果の持続性や,
データ量と学習回数の最適な関係についても,
今後の課題として残されている.
